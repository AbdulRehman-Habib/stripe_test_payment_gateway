## 📌 Setup Guide (Quick)

- Install XAMPP  
- Place project in: C:\xampp\htdocs\stripe
- Run Apache from XAMPP  
- Install dependencies: composer require stripe/stripe-php
- Open in browser:


http://localhost/stripe/index.php
