### stripe_test_payment_gateway
🚀 Modern Stripe Payment Gateway Integration in PHP using XAMPP + VS Code

A beginner-friendly Stripe Checkout integration project built with PHP, XAMPP, Composer, and Stripe Checkout Sessions.

#✨ Features:
• Modern glassmorphism UI
• Secure Stripe Checkout integration
• Sandbox/Test mode payments
• Beautiful Success & Cancel pages
• Responsive payment interface
• Clean PHP project structure

#🛠 Tech Stack:
• PHP
• Stripe API
• XAMPP
• Composer
• VS Code
• HTML/CSS

#💳 Stripe Features Used:
• Stripe Checkout Session
• Secret Key Authentication
• Test Payment Flow
• Secure Redirect-based Checkout

#📚 Perfect for beginners learning:

• Stripe API basics
• PHP backend development
• Composer setup
• Localhost development with XAMPP
